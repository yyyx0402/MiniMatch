# 当前模型质量与使用范围

固定 140,084 件商品，1,000 条官方测试查询。这些查询在此前开发中已经使用，本报告是固定模型回归检查，不能称为新的未查看测试。训练、验证与测试规范化查询保持隔离；当前模型和融合权重在本次检查前固定，评估不会重新选模。

| 检索方法 | 已标注 E Recall@100 |
|---|---:|
| BM25 | 65.3345% |
| 未微调 MiniLM | 66.9220% |
| 微调后的 MiniLM | 68.6941% |
| 未微调混合 | 72.8213% |
| 当前智能搜索 | 73.4689% |

微调单模型增加 1.7720 个百分点，2,000 次按查询配对 bootstrap 的 95% 区间为 [0.8796, 2.6346] 个百分点。微调混合相对未微调混合增加 0.6475 个百分点，区间为 [-0.0515, 1.3243] 个百分点，包含零，不能声称这一混合增益有明确统计证据。

在相同人工标注候选列表上，未微调与微调的 NDCG@10 为 0.7097 和 0.7173。这与全库召回是不同评测任务。

MiniLM、BM25 与 RRF 是已有方法。项目工作是商品任务微调、监督关系处理、质量评估与应用集成，不声称发明新编码器或新融合算法。标注不完备，未标注商品不能直接当作明确不相关；模型分数也不是购买概率。

本机六条查询的服务层智能搜索未缓存耗时中位数约 48 ms，缓存命中约 2 ms。商品库与指纹加载加首次查询约 3.44 秒；不含 Python 导入、HTTP 传输与浏览器渲染，不是并发负载测试。使用 `scripts/benchmark_application.py` 在自己的电脑重新测量。

当前界面通过浏览器验证：三种搜索、商品详情、继续加载、跨搜索比较、三件上限、刷新恢复、空结果和输入错误恢复。公开源码包含 32 项当前检查，独立源码环境为 21 项通过、11 项真实产物检查按预期跳过；本机包含历史回归的完整检查为 64 项全部通过。
